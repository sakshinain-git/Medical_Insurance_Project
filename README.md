# Medical Insurance Cost Prediction

## 📌 Project Overview

This project focuses on analyzing medical insurance data and predicting medical insurance charges using Python and Machine Learning techniques.

## 📂 Project Files

- insurance.csv - Main dataset used for analysis and model development.
- Workbook1.csv - Additional dataset/output file.
- medical_insurance.py - Python source code for data analysis and machine learning.
- medical.docx - Project documentation/report.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Python

## 🔍 Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Feature Preparation
6. Model Training
7. Model Evaluation
8. Insurance Charge Prediction

## 📊 Dataset

The dataset contains information related to medical insurance such as:

- Age
- Sex
- BMI
- Number of children
- Smoking status
- Region
- Medical insurance charges

## 🎯 Objective

The main objective of this project is to understand the factors affecting medical insurance charges and build a machine learning model capable of predicting insurance costs.
